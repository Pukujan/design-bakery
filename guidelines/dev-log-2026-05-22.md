## Follow-up (same day) — Firebase exit → Supabase migration

**Decision:** Move off Firebase to **Supabase** (PostgreSQL + Auth + Storage).

**Why (errors / blockers):**

| Problem | What we saw |
|---------|-------------|
| Firebase Storage | `The specified bucket does not exist` — Storage never provisioned on Spark |
| Billing | Blaze required for Storage; setup failed `[OR_BACR2_44]` + $10 prepayment prompt |
| Firestore + Save | Posts must store **HTTPS image URLs**, not huge `data:` previews (~1 MiB doc limit); without Storage, Save/commit_visual failed |
| Oracle alternative | Rejected — too much custom integration for this repo |

**Supabase = Postgres:** Database is real **PostgreSQL** (SQL, JSONB, migrations in `supabase/migrations/001_initial.sql`). Image bytes go to **Supabase Storage**, not Postgres rows.
