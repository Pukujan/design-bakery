# Dev Log - 2026-05-18

## Summary

Polished the public blog detail experience (layout, typography, Mermaid diagrams), improved admin reliability (Firebase login messaging, blog editor overflow), and moved the Vite dev server off port 5173 so it can run alongside other local apps. Earlier in this branch: in-app Ekagajpatra case study at `/case-studies/ekagajpatra` (commit `6fd7467`).

## Changes Made

### 1. **Blog Detail Page** (`src/app/modules/engineering/BlogDetailPage/BlogDetailPage.tsx`)

**Layout & overlap fixes**
- Removed fixed-position Back button that overlapped the article title.
- Back button and mobile sidebar toggle now sit in normal document flow above the article.
- Constrained page to `max-w-4xl` with `overflow-x-hidden` so content does not spill past the viewport.
- Sidebar (categories / quick actions) only shows on `xl+`; mobile uses a menu toggle.
- Removed decorative blobs/cupcake/flower from the detail page to reduce clutter.

**Typography & spacing**
- Reduced title to `text-xl` / `text-2xl` (from very large clamp values).
- Markdown body uses `text-xs` custom components and `prose-sm`-level density.
- Tighter margins on headings, paragraphs, lists, blockquotes, and code blocks.

**Duplicate title**
- Blog JSON includes `# Title` in markdown while the page header also renders `blog.title`.
- Added `stripLeadingMarkdownTitle()` to remove the first `# …` line from rendered markdown.

**Mermaid diagrams**
- Switched from `mermaid.contentLoaded()` + raw chart text to `mermaid.render()` for reliable SVG output.
- Initialized Mermaid with smaller `themeVariables` and tighter flowchart spacing.
- **Issue:** `transform: scale()` + `overflow: hidden` + measured height collapsed diagrams to zero height → charts disappeared.
- **Fix:** Render SVG via `dangerouslySetInnerHTML` in a simple container; size with CSS `zoom: 0.48` and `max-width: 280px` on `.blog-mermaid-diagram` (see `globals.css`).
- Horizontal scroll on code blocks preserved for long lines.

Labels forced to ~8–10px for readability at small scale.

### 3. **Admin login & Firebase** (`AdminLogin.tsx`, `firebase.ts`)

**Problem:** No `.env` file in repo (gitignored). Vite had no `VITE_FIREBASE_*` vars → `auth` was `null` → sign-in threw *"Firebase Auth is not configured"* or the flow felt broken.

**Changes**
- Exported `isFirebaseConfigured` from `firebase.ts`.
- Admin login shows an amber alert when env vars are missing, with steps: copy `.env.example` → `.env`, restart dev server; note Vercel env vars for production.
- Clearer Firebase Auth error messages (`auth/invalid-credential`, `too-many-requests`, etc.).
- Redirect to `/admin` when already signed in.
- **Local setup:** `.env` created from `.env.example` (not committed).

**Admin URL:** `http://localhost:5300/admin/login` (after port change).

### 4. **Admin blog editor overflow** (`BlogEditor.tsx`, `textarea.tsx`)

**Problem:** Pasting very long unbroken lines (URLs, tokens) expanded the edit dialog horizontally; default `Textarea` used `field-sizing-content`, which grows with content width.

**Changes**
- Dialog: `overflow-x-hidden`, `w-[calc(100vw-2rem)]`, `max-w-3xl`.
- Form wrapper: `min-w-0 overflow-hidden` on grids and field groups.
- Shared classes:
  - `FIELD_OVERFLOW` — inputs: `min-w-0 max-w-full overflow-x-auto [overflow-wrap:anywhere]`
  - `TEXTAREA_OVERFLOW` — textareas: `field-sizing-fixed`, scroll, `whitespace-pre-wrap`, break long tokens
- Applied to title, author, excerpt, date, readTime, color, tags, and **Content (Markdown)** fields.
- Base `Textarea` component default changed from `field-sizing-content` to `field-sizing-fixed` + `min-w-0 max-w-full` (affects all admin textareas).

### 5. **Dev server port** (`vite.config.ts`)
