# design-bakery-frontend

Vite + React app. Env: `frontend/.env` (see `.env.example`).

```bash
# From repo root
pnpm --dir frontend run dev
pnpm run build   # builds frontend only
```

See [additionals/doc/env.md](../additionals/doc/env.md) and [docs/self-hosting.md](../docs/self-hosting.md) for deploy.
