The market gap

We have tools for memory, tools for decisions and tools for observability. The reasoning in between still falls through the cracks.

Today's stack is good at remembering facts, recording final decisions and showing what an agent executed. It is much weaker at preserving the evidence trail that made a technical belief worth acting on.

AI memory

“What should the agent remember?”

Mem0, Zep, Letta and similar systems make long-running agents more useful by carrying context forward.

Decision records

“What did we decide?”

ADRs, architecture records and decision-intelligence products capture important choices — usually as explicit records around the final decision.

The missing layer

“Why was this justified then — and is it still justified now?”

Research, source evidence, assumptions, failed tests, objections, supersession and dependent conclusions rarely survive as one inspectable history.

FOSSIL is for the part between remembering and deciding: the history of how the project came to know what it knows.
The business problem

When the reasons disappear, teams pay for the same thinking twice.

Without a durable reasoning record

Someone searches old chats. Another person reruns research. A new agent resurrects a rejected approach. A stale assumption quietly survives inside a design. The team spends time reconstructing history instead of moving forward.

With FOSSIL

Ask why. See the current decision, the old one, the evidence that changed it, the alternatives that lost, and the parts of the project that now deserve another look. Then keep working.

Positioning

FOSSIL does not need to replace memory. It can become the authority layer that memory retrieves from.

Use memory for

  • Recall: preferences, context and useful prior facts
  • Personalization: what this user or agent tends to need
  • Fast retrieval: what is relevant right now

Use FOSSIL for

  • Justification: what evidence made a claim worth acting on
  • Change: what was superseded, disputed or made stale
  • Reconstruction: how the project got from the old position to the current one
