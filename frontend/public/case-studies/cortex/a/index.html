Cortex case study / constrained execution

A kernel, not a smarter agent.

Cortex sits beneath agent reasoning. It authorizes every effect, denies what is not explicitly allowed, routes tools through a sole writer, and produces a receipt for the resulting state change.

01

Put consequence behind a boundary.

Cortex separates deciding what to attempt from possessing the authority to do it. A plausible plan is still only a request until the kernel evaluates its declared scope and policy.

Step 01

An intent names the requested operation, target, and relevant context.

Step 02

Step 03

Broker executes

Step 04

02

Seven mechanisms, one enforceable path.

Each mechanism narrows ambiguity at a different point in execution. Together they turn an agent's proposed action into an authorized, attributable state transition.

Request envelope

Every proposed effect arrives as a structured request with an actor, intent, target, and context that can be evaluated before execution.

Deny by default

No action inherits permission from confidence, conversational context, or a model's interpretation. Unproven authority is a denial.

Explicit authority

Authorization is tied to declared capabilities and scope, not to the agent's ability to discover or invoke a tool.

Policy gate

Policy is evaluated at the effect boundary, where the requested operation and its concrete target are both visible.

Brokered tools

Tools are reached through tool_broker. The agent proposes calls but does not hold an independent write path.

Sole-writer commit

tool_broker is the sole writer, keeping committed state changes on the same path as authorization and policy enforcement.

Execution receipts

Each completed or denied request produces durable evidence connecting the proposal, authorization decision, tool outcome, and resulting state.

The ownership boundary

tool_broker is the sole writer.

The architecture does not rely on every planner, tool wrapper, or downstream service remembering the same rules. Writes converge on one controlled commit path.

One place to authorize. One place to commit. One chain of evidence.

04

Different from adding more intelligence.

Cortex addresses control of effects. It does not claim that better reasoning, tool wrappers, or post-hoc logs provide the same guarantee.
