Cortex

A checkpoint between an AI that writes code and the code that actually ships.

An AI assistant can suggest changes to software. Cortex makes sure it can never make one on its own.

  • 01The AI proposes. It cannot write.
  • 02Nothing reaches the real code without a human approving that exact change.
  • 03Every approval is a permit that works once, and only for the thing it was issued for.

The problem

Giving an AI the keys is the easy part. Getting them back is not.

Most AI coding tools are handed the same access a developer has: edit files, commit, push. When it works, it is fast. When it goes wrong, there is often no record of what changed, who allowed it, or whether anyone did.

The usual answer is to review the AI's work afterwards. That only holds while a person is genuinely reading every line, which stops being true almost immediately.

How it works

Five steps, and a refusal available at every one.

If any step fails, nothing happens at all. The safe outcome is always "no change".

The central idea

The permit is the whole trick.

An approval is not "yes, go ahead". It is a permit bound to one specific change, valid once. Change a single character afterwards and the permit no longer matches, so the write is refused.

Why trust it

Six answers, in the order they matter.

What worries peopleWhat Cortex does about it
"The AI could do something I didn't ask for." The AI holds no keys. A separate, ordinary program does all writing, and only accepts changes carrying a valid permit.
"What if something slips through?" Everything is refused unless explicitly allowed. No path where silence or an error means "go ahead".
"How do I know what was approved is what was done?" The permit is tied to a fingerprint of the exact change, re-checked at the last moment before writing.
"Could it reuse an old approval?" Permits work once and are spent on use. A used permit is refused.
"You wrote the tests, so of course they pass." It is judged against security requirements published in 1972, which nobody here wrote and nobody here can edit.
"Every project claims it's secure." This one publishes what is not working, including a requirement it failed until this week.

The finding that matters

Three AI models from different companies, shown only the code and never the tests, found nine real defects that a fully passing test suite had missed.

Tests passing is not evidence that a system works. Building the thing that can tell the difference is what Cortex is for.
