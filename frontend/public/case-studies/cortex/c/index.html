01

Capable is not the same as trustworthy.

AI coding agents remain probabilistic, so consequential output still needs verification proportionate to its risk. A stronger model can reduce errors; it does not establish correctness or authority.

Ungoverned agent path

A better driver

A stronger model, richer prompt, or larger toolset may reduce errors. Without an independent control path, the model's proposal can still become an action before an external authority verifies it.

Cortex

A control plane around the driver

Assume the agent is fallible. Put enforceable boundaries between proposals and consequential actions, bind approvals to exact artifacts, and keep independent evaluation outside the builder. The controls reduce risk; they do not certify the product by themselves.

02

The move operating systems made fifty years ago.

You do not trust every program to avoid corrupting memory; you put enforceable boundaries between programs and hardware. The target architecture applies that reference-monitor pattern to an agent acting on a repository. Cortex has component-tested kernel mechanisms, but the production agent path does not yet run through the composed kernel. Three commitments follow — each stamped at its real state.

04

Eight visible tests passed. The release was still blocked.

A recorded decision, a green suite, and an independent review that stopped the release anyway. The frozen v1.4 recovery decision is kept separate from the nonconformant composition that failed to honor it — that separation is the point.

  1. 01 · recorded decision · frozen

    Embed the invariant in storage

    The recorded v1.4 decision requires that APPROVED and a non-null diff_hash commit atomically, and that an approved run recover its exact diff hash from one durable record. A receipt may report that event; it cannot become a second source of truth. The amendment itself is frozen.

    RECORDED // master amendment v1.4 + freeze record
  2. 02 · builder claim

    Run the visible suite

    The composition entrypoint reached its expected states and all eight focused tests passed. Useful evidence — but only for the paths those tests exercised.

    OBSERVED // 8 passed
  3. 03 · independent review · blocked

    Trace the restart path

    The projection permitted APPROVED without a hash, and recovery joined receipt data back into the run. That violated the recorded v1.4 recovery decision — the nonconformance is in the composition, not in the frozen amendment.

    VERDICT // FAIL · release remains blocked
  4. 04 · acceptance target

    Make the failure impossible

    The repair must atomically store status and hash, recover without receipt joins, and pass a restart test written outside the builder lane.

    NEXT // builder repair → independent holdout → owner review
Component tests are evidence, not release authority. The refusal to convert green tests into an automatic release claim is the product.

06

Established mechanisms, recomposed for agent reliability.

The architecture draws on named reference-monitor, privilege-separation, content-binding, and workload-isolation patterns. Precedent informs the design; it does not prove this implementation.

  • 1972The reference monitor. Anderson's study, then Saltzer & Schroeder (1975): least privilege, complete mediation, fail-safe defaults. Those principles influenced authorize().
  • 2003Privilege separation. OpenSSH's tiny privileged monitor with unprivileged workers that hold nothing (Provos, Friedl, Honeyman). The broker is this pattern.
  • 2009Capability & content binding. seL4's verified capability microkernel; Macaroons (2014); Merkle hashing that binds a token to an exact hash as git and Sigstore do. The receipt is this.
  • 2020Trust-graded isolation. Firecracker and gVisor as established workload isolation. Cortex's risk grading is its own composition, and production execution is not live.
Prior-art studies and independent critique came before implementation. Parts were adopted where they fit and rejected with recorded reasons where they did not. The claim is the composition and the evidence trail, not new primitives.
