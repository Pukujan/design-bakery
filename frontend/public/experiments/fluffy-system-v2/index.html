Why v2 is smaller

Choice generation is a different task from design refinement.

Choice pressure rewards novelty.

When an agent is asked for many options at once, attention goes into making each option visibly different. That often means palette, metaphor, and surface changes instead of deeper typography, spacing, hierarchy, interaction, and copy work.

Every variant inherits less context.

Good design is iterative. A single page can absorb several rounds of local reasoning. Eight simultaneous pages usually get one broad pass each, so mistakes survive because there is no focused critique loop.

Shared context makes variants converge.

The same brief, same recent copy, and same component ideas remain active while generating the set. The pages may look different at thumbnail size while sharing the same underlying section rhythm and synthetic voice.
