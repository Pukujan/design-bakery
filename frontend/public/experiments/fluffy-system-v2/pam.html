02 · Why now

Code generation is accelerating faster than confidence in the work around the code.

“Move beyond AI coding to agentic engineering.”

Kiro's current positioning is a useful market signal: modern coding tools are moving from prompt-to-code toward requirements, design, tasks, testing, and longer-running agents. The planning surface is becoming productized.

Kiro · spec-driven development

More throughput can expose weak foundations.

DORA's 2026 analysis says AI accelerates initial code generation while time is often reallocated to auditing and verification. Its findings associate higher AI adoption with more delivery throughput and more delivery instability.

03 · The market gap

Specs organize implementation. PAM asks whether the project earned its assumptions.

The practical alternatives already exist: senior-engineer memory, internal playbooks, ADRs, project templates, issue templates, spec-driven coding tools, long system prompts, and generic planning modes. PAM focuses on the reusable assurance obligations that should survive across tools and sessions.
