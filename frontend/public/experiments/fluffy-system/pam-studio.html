A checkbox can pass while the work never happened.

An agent wrote a plausible candidate list. Frameworks had names. The mission engine, the actual product, was justified against an abstract category. PAM itself showed up as if it were a runtime alternative. Dataset discovery was skipped.

That is not a cute process miss. It is how AI-assisted planning fails in public: fluent, complete-looking, and empty where it counted.

PAM is the versioned preflight that refuses to treat a self-authored decision file as proof that research occurred.

Make the project earn its shape before the backlog hardens.

PAM is not a runtime stamp and not a promise that the research conclusion is true. It is a versioned methodology registry: pin an exact revision, route only the work that applies, close it with evidence a later human or agent can reopen.
