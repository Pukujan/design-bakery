02 · What PAM is selling

The first commit should inherit decisions that were made on purpose.

Before implementation

Declare what the project is trying to prove, what work applies, what should be reused, and what evidence will count.

During implementation

Requirements close against files, tests, CI, benchmark artifacts, exact revisions or reviewed decisions where possible.

Across agents and sessions

The handoff is structured enough that the next agent does not have to reconstruct the project's intent from chat history.

Current wedge

AI made it cheap to start building. PAM asks whether the project has earned the right to start.

That is a project-planning story, not a methodology inventory. The modules matter because they turn forgotten engineering work into explicit preflight.
