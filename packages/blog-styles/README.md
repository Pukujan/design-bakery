# @design-bakery/blog-styles

Blog component CSS extracted from design-bakery `globals.css`.

## Usage

```css
@import '@design-bakery/blog-styles/tokens';
@import '@design-bakery/blog-styles/blog';
```

For creator + preview only:

```css
@import '@design-bakery/blog-styles/preview';
```

Enable Tailwind v4 to scan `@design-bakery/blog-*` package paths in the host Vite app.
