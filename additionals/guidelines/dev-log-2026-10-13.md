### The mechanics worth remembering

- **The bloom rides the one eased clock.** `--bloom-op` closes over the arrival beat —
  `bloomOut = clamp((vh / max) * 0.85, 0.008, 0.5)`, derived from the viewport's share
  of the page rather than fixed — and is fully 0 before `--work-fg` opens, so the
  blossom can never stack with the near branch plane. No second scroll listener was
  added; the TASK-DB-0087 constraint holds.
- **Sway never fights the filled animation.** The one-shot `db-bloom-open` fills
  `transform` (`animation-fill-mode: forwards`); the ambient 15 s sway animates
  `translate`, a different property channel, so the filled state and the infinite
  ambient loop coexist.
- **Card emphasis never reads layout in the frame.** Card document-space centres are
  cached in `measure()` (resize / load / fonts only); the frame turns each into a
  distance from the eased viewport middle and writes `--card-emph` only when the value
  changes. Floor is the dim edge state (0.42) — a card is never removed.
- **Reduced motion** composes to a still frame: buds hidden, full plate drawn,
  animations none, every card settled at centre emphasis.
