## Summary

Added and then revised a small FOSSIL marketing project using the existing Cortex static-HTML case-study pattern. The public v2 stays problem-first, adds external software-engineering evidence, explains why ordinary AI memory is a different contract, includes current AI adoption/economic signals, maps adjacent memory/ADR/decision-intelligence products honestly, labels FOSSIL's own benchmark as internal, and keeps a separate evidence ledger with limitations and rejected claims.

## Changes Made

- Added the original standalone page at `frontend/public/case-studies/fossil/index.html`.
- Added the evidence-led public v2 at `frontend/public/case-studies/fossil/v2/index.html`.
- Frames the user problem before introducing FOSSIL features.
- Uses externally sourced numbers from ICPC, JSS, UIST, ICLR, TACL, Stack Overflow, Menlo Ventures, and Gartner.

### 2. Interactive presentation
- Added the original `frontend/public/case-studies/fossil/presentation.html`.
- Added `frontend/public/case-studies/fossil/v2/presentation.html` with the expanded problem / why-now / market framing.

- Keeps prose conversational and short; technical terminology appears only after the problem is established.

### 3. Evidence ledger
- Added the original `frontend/public/case-studies/fossil/evidence.html`.
- Added `frontend/public/case-studies/fossil/v2/evidence.html`.
- Separates academic evidence, developer survey evidence, market estimates, analyst forecasts, current product pricing, competitive landscape, and FOSSIL's internal six-case benchmark.
- Records a limitation under every major claim.
- Records rejected claims such as “memory doesn't work,” “FOSSIL perfectly recreates everything,” and “FOSSIL has no competitors.”

### 4. Market / competitor review added to v2
- Memory infrastructure examples: Mem0 and Zep/Graphiti.
- Decision / architecture examples: adrkit, Ardoq Architecture Records, and Cloverpop Decision Intelligence.
- Public positioning deliberately avoids claiming that no competing or overlapping system exists.
- The narrower FOSSIL positioning is source-grounded epistemic lineage across evidence, claims, assumptions, disagreement, dependencies, lifecycle, and historical/current state.

### 5. Pretty routes
