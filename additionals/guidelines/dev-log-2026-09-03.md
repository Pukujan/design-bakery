## Summary

Added a small FOSSIL marketing project using the existing Cortex static-HTML case-study pattern. The project is deliberately problem-first: external software-engineering research establishes the rationale/context-loss problem, memory is treated as useful but distinct from provenance, FOSSIL's internal benchmark is labeled as internal, and a separate evidence ledger records limitations and rejected marketing claims.

## Changes Made

### 1. FOSSIL case study
- Added a standalone long-form page at `frontend/public/case-studies/fossil/index.html`.
- Framed the user problem before introducing FOSSIL features.
- Added externally sourced numbers from ICPC, JSS, UIST, ICLR, and TACL papers.
- Added a simple epistemic-lineage example (`supported`, `superseded`, `stale_pending_review`).
