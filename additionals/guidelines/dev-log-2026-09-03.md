## Summary

Built and iterated the FOSSIL marketing case study using the existing Cortex static-HTML presentation pattern. After the evidence-led v2 read too much like an audit / feature showcase, v3 was rewritten around the commercial gap and buyer outcome: AI-assisted work is producing more consequential technical reasoning, but the durable record of why that reasoning became justified is still fragmented across memory systems, chats, logs, ADRs, sources, and observability tools.

## Current public narrative (v3)

### 1. Market gap first
- Lead: **“AI can make the decision. Who remembers why?”**
- Frames three layers:
  - AI memory: what should the agent remember?
  - decision records: what did we decide?
  - FOSSIL's wedge: why was this justified then, and is it still justified now?
- Does not claim the market is empty; adjacent products remain acknowledged.

### 2. Buyer value before implementation detail
The main page now sells:
- less repeated research;
- better handoffs;
- fewer resurrected rejected approaches;
- earlier detection of stale reasoning;
- more confidence delegating consequential work to agents.

The key product line is **“your project can show its work.”**

### 3. One simple demo
The primary product demonstration is one question:

> Why did we move off SQLite?

The answer shows the current decision, what changed, what lost, and what dependent work now needs review. Technical ontology / lifecycle detail stays behind the user-facing outcome.

### 4. Why-now / economic framing
Public timing evidence stays limited to a few legible signals:
- Stack Overflow 2025: 84% use or plan to use AI in development;
- Stack Overflow 2025: 46% distrust AI accuracy;
- Menlo Ventures: estimated $4B enterprise AI-coding spend in 2025.

These are explicitly market-timing signals, not proof of FOSSIL product-market fit.

### 5. Market wedge
The presentation now moves from:
1. agentic individual developers;
2. engineering / research teams;
3. high-consequence knowledge work.

The commercial thesis is that the first sale is productivity; the larger sale is durable institutional knowledge and trust.

### 6. Positioning against memory
The public story no longer attacks memory systems. It positions FOSSIL above / beside them:
- memory = recall, context, personalization, fast retrieval;
- FOSSIL = justification, change, historical reconstruction.

Short version:

> Memory asks “what should I remember?”  
> FOSSIL asks “why should I believe this?”
